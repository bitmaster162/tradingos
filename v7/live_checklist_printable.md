# Live Checklist v7

_Одностраничный чек-лист перед нажатием кнопки. Если пункт не проходит, сделки нет._

## Context
- Bias: H1/H4 задаёт направление, вход исполняется на M15, триггер уточняется на M5.
- Есть ли понятный режим: trend / mean-revert / expansion?
- Есть ли уровень, ликвидность и понятная инвалидация, а не просто идея?

## Setup
- Composite confirmations: минимум 2 независимых подтверждения перед входом.
- Сетап назван заранее: PB-Trend / LIQ-Sweep / VWAP-MR / Range-Fade / FakeBreak.
- Вход записан одной строкой: условие -> цена -> инвалидация -> цели.

## Risk
- Risk per trade: 0.5% рабочего риска, диапазон 0.25-1.0% только по плану.
- Daily stop: -2%; Weekly stop: -6%. После стопа день закрыт.
- Portfolio: максимум 2 живые позиции, учитывать корреляцию BTC/ETH.
- Размер считается из `size = (equity * risk%) / stop_distance`, а не из настроения.

## No-Trade
- No trade: пропускать окно 5 минут до/после major releases.
- Нет усреднения, догонов и мести рынку.
- Если нет фокуса, есть FOMO, злость или желание вернуть - пауза и запрет на вход.

## Execution
- До входа известны `entry`, `stop`, `TP1`, `TP2`, правило BE и сценарий отмены.
- После первого тейка: перенос стопа по плану, не переизобретать сделку внутри сделки.
- Если контекст меняется против плана, закрывать по правилу, а не уговаривать рынок.

## Post-Trade
- Записать результат и нарушение сразу после сделки.
- Отдельно отметить: соблюдён ли сетап, риск, тайминг, новостной фильтр и kill-switch.
- Следующее увеличение риска только после метрик, а не после серии эмоций.
