# Post-census continuation contract

M2A stops before outcomes. A successor M2B may start only after all conditions
below are independently satisfied.

1. Antigravity delivers an exact `EDGE_DATA_CATALOG.json` and per-hypothesis
   readiness records.
2. The controller adjudicates the census and issues a new hashed task whose ID
   is not `TRADING_EDGE_RESEARCH_ENGINE_M2A`.
3. The selected hypothesis is not a renamed M1 H2/H3 family and any M1 H1
   continuation uses only a new independent sample.
4. Exact preregistration is compiled before final-test access.
5. Catalog SHA, required channels, provenance, timestamp semantics, freshness,
   missingness, duplicates, clock skew, and join coverage pass deterministic
   derivation.
6. Outcome budget is explicitly `ALLOW`; trading, capital, deployment, and
   self-application remain denied.

M2B must add a separately reviewed immutable-packet reader. It must not weaken
the M2A gates, overwrite M1 truth, or interpret a research terminal as edge or
runtime acceptance.
