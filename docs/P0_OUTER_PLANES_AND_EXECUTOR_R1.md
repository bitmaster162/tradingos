The key anti-bypass rule is:

```text
caller command + caller-declared READ_LOCAL
!= trusted effect classification
```

A trusted broker must derive effect class from a typed operation and route only through operation-specific handlers. Approval resolution remains external to the executor.

Vendor session state is not durable project truth. A ResultEnvelope or COMPLETE claim is not an AcceptanceDecision.
